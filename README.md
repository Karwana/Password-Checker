# Password Checker

Console-based Java application that checks password strength and generates secure passwords.

## Features

- **Check password strength** – Scores your password from 0–10 based on five criteria:
  - At least 10 characters
  - Uppercase letter
  - Lowercase letter
  - Digit
  - Special character
- **Improvement tips** – Shows which requirements your password is missing
- **Generate a secure password** – Creates a random 10-character password that meets all requirements

## Getting Started

```bash
git clone https://github.com/karwana/password-checker.git
cd password-checker
```

Open the project in your IDE and run `Main.java`.
